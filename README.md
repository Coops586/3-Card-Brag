# Bastard Brag Premium Prototype

Real-time social card game prototype for 2–6 players.

## Included
- Create / Join private room
- 5-character room code
- 2–6 players
- Player names and avatars
- 3 or 5 starting lives
- Private hand for each connected player
- Shared middle 3-card hand
- Swap 1 or 3 cards
- One swap per turn
- Knock and final-turn flow
- Lives/elimination
- Round reveal
- Rematch
- Session win counter
- Mobile-first card-table design
- Swap and knock feedback

## Run
Requires Node.js 18+.

npm install
npm start

Then open http://localhost:3000

## Deploy
This is a Node/Socket.IO app, so use a host that supports persistent Node processes and WebSockets, such as Render, Railway, Fly.io, or a VPS.

## Before charging users
This prototype has no accounts, payments, moderation, persistent database, reconnect tokens, analytics, privacy policy, terms, age rating workflow, or app-store billing.
Those should be added before commercial launch.

Keep the game social/play-money unless you obtain specialist legal advice and any licences required for real-money gambling.
